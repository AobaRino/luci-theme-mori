## 实机安装

在已有同版本 Mori 独立安装的设备上，先模拟仅安装 Mori、保存私有备份，再使用临时公钥目录安装上述同一份 APK。安装保留包自身脚本，跳过设备额外的全局事务钩子。

- 22 个文件的 SHA-256 与成品一致，6 个模板可编译，Mori 已交由 APK 管理。
- 主题选择、全部路由器配置、受保护的代理运行文件、原有主题文件、UCI 草稿和服务进程 PID 均保持不变。
- 软件包清单仅新增 `luci-theme-mori`。
- 首页刷新后正常显示 Mori、状态摘要及下方系统信息，浏览器未记录错误。
- DNS 解析、直连 HTTPS（200）与既有代理 HTTPS（204）检查通过。

实机未执行卸载或跨版本升级；卸载路径在隔离 rootfs 验证。其他架构、固件版本及旧版 `.ipk` 不属于本次验证范围。私有设备配置和部署备份不包含在仓库或发布附件中。
